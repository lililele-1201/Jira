# 校园团队协作任务管理系统：任务节点与风险提醒设计

## 目标

在现有项目、Epic 和拖拽看板功能上，增加一组轻量的任务节点管理能力，让课程小组、竞赛团队和课题组能快速识别临期与逾期任务。项目展示名称统一为“校园团队协作任务管理系统”。

## 功能范围

- 任务增加优先级 `low | medium | high` 和可选截止日期 `dueDate`。
- 创建、编辑任务时可设置优先级和截止日期，旧数据缺少字段时仍能正常显示。
- 看板卡片展示负责人、优先级和到期信息。
- 截止日期早于当天时标记为“已逾期”；今天起 3 天内到期时标记为“即将到期”。
- 筛选栏提供“仅看我的”、“已逾期”和“即将到期”，并与现有 URL 查询参数同步。
- 保留现有 Mock API 和 React Query 数据流，不引入真实后端。

## 实现设计

日期风险判定作为无副作用工具函数，输入截止日期和当前日期，输出 `normal | dueSoon | overdue`。看板卡片与筛选逻辑共用该结果，避免规则重复。筛选组合在客户端对 React Query 返回的任务列表进行派生，不伪造 Mock 服务端未实现的查询能力。

## 容错与兼容

- 未设置截止日期的任务不参与到期筛选，也不显示警告。
- 旧任务未设置优先级时按“中”展示，不强制批量迁移数据。
- 继续使用现有任务编辑 mutation 和错误反馈，不另建一套状态。

## 验证

- 为风险判定覆盖无日期、未到期、3 天内到期和已逾期边界。
- 为组合筛选覆盖负责人与风险状态同时生效。
- 手动验证创建、编辑、重新加载后字段保留，以及 URL 筛选状态可恢复。
- 运行生产构建，保证未增加新的 TypeScript 或 ESLint 错误。

## 非目标

不增加真实后端、消息通知、日历、图表仪表盘、多人实时协作或权限系统。
